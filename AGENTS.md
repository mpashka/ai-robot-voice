# AGENTS.md — `ai-robot-voice`

Плагин Claude Code и Codex: голос робота и обратная связь о том, как поставлена задача. Что он делает,
как ставится и какие есть настройки — [`README.md`](README.md), он же документация плагина.

**Язык репозитория — русский**: робот говорит по-русски, и тексты правил в `prompts/` — его
реплики, а не служебные строки.

## Границы

- 🚨 **Машинного тут нет.** Настройки, история реплик и счётчики живут в
  `~/.config/robot-voice-hook/` и в репозиторий не едут. Появилось значение, которое на одной
  машине одно, а на другой другое, — это ключ `settings.json`, а не константа в коде.
- **Значки не врезаются в тексты.** В `prompts/` стоят `{{mark_high}}`, `{{mark_mid}}`,
  `{{mark_low}}`; наборы — `markSets` в `hooks/inject-voice-rule.js`, выбор — ключ `marks`.
- **Ядро инъекции — 1 900 байт.** Больше — и оно перестаёт умещаться в превью, которое Claude
  Code оставляет от длинного `additionalContext`; робот замолкает. Хук об этом предупреждает сам.
- Проверка без звука, метрик и записи состояния — `ROBOT_VOICE_HOOK_DRY_RUN=1`, классификатор
  отключается `ROBOT_VOICE_CLAUDE_BIN=/bin/false`.

## Как попадает на домашние машины

Значения настроек — реестр `configs` (`group_vars/workstations.yml`, `host_vars/<машина>.yml`),
раскладка `~/.config/robot-voice-hook/settings.json` и объявление плагина в `~/.claude/settings.json` —
роль `ai_agents` в `home-infra` (`cfg ansible apply ai-agents`). Правится значение — правится
реестр, а не файл на машине.

## Грабли

- 🚨 **`hooks` в `plugin.json` не пишется.** Файл `hooks/hooks.json` Claude Code загружает сам,
  а ссылка на него в манифесте делает его вторым — плагин отваливается целиком с «Duplicate
  hooks file detected». Ключ нужен только для хуков в файле с другим именем. В
  `.codex-plugin/plugin.json` ключ `hooks` стоит: так объявлены хуки у рабочей установки Codex.
- 🚨 **`hooks/hooks.json` не правится мимоходом.** Codex хранит доверие к хукам хэшем в
  `~/.codex/config.toml`, и правка файла означает интерактивный перевыпуск доверия на каждой машине.
- **Версия — в трёх местах**: `.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json`,
  `.codex-plugin/plugin.json`. Установленные копии обоих агентов обновляются только по её подъёму.

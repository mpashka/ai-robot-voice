# robot-voice — плагин Claude Code: голос робота и обратная связь о постановке

Плагин вешается на два события Claude Code и делает из них обратную связь **о том, как
поставлена задача**, а не о том, как справился агент.

- **Перед работой** классификатор (отдельный дешёвый запуск `claude`) оценивает запрос по двум
  осям — понятность и объём — и хук отдаёт агенту стартовую реплику робота со значком.
- **После работы** агент по правилам из `prompts/` заканчивает ответ строкой `🤖 <реплика> <значок>`
  и одним советом: чего не хватило в постановке, какое допущение пришлось принять.
- **Голос** (если включён): та же строка произносится вслух через RHVoice.

Значок один и цветной: 🟢 работать можно, 🟡 придётся додумывать, 🔴 работать не с чем. 🚨 Главный
сигнал — **расхождение стартового и финального цвета**: первый говорит, как запрос выглядел,
второй — чем оказался.

Робот говорит по-русски и в характере: сухой мизантроп. Тексты правил лежат в `prompts/` и
правятся без трогания кода.

## Установка

```
/plugin marketplace add mpashka/ai-robot-voice
/plugin install robot-voice@ai-robot-voice
```

Того же добиваются два ключа в `~/.claude/settings.json` — именно так плагин приезжает на мои
машины (роль `ai_agents` в `home-infra`, значения в реестре `configs`):

```json
{
  "extraKnownMarketplaces": {
    "ai-robot-voice": { "source": { "source": "github", "repo": "mpashka/ai-robot-voice" } }
  },
  "enabledPlugins": { "robot-voice@ai-robot-voice": true }
}
```

Голос — необязательная часть: без `RHVoice-test` и `ffplay` робот просто молчит, текстовые
реплики остаются. Классификатор — тоже: без доступной команды `claude` значок сменится на ❔,
а причина будет названа словами.

## Настройки

Все значения — `~/.config/robot-voice-hook/settings.json`. Файла нет — работают умолчания,
плагин самодостаточен.

| Ключ | Умолчание | Что делает |
|---|---|---|
| `marks` | `circles` | набор значков: `circles` 🟢🟡🔴 или `books` 📗📙📕 |
| `mat_level` | `high` | грубость: `normal`, `high`, `very_high` — сколько вставок из перечня в реплике |
| `debug` | `false` | показывать стартовую реплику отдельным сообщением (иначе её видит только агент) |
| `start_enabled` | `true` | стартовая реплика перед работой |
| `question_enabled` | `true` | реплика перед уточняющим вопросом |
| `audio_enabled` | `true` | произносить реплики вслух |
| `voice` | `mikhail` | профиль RHVoice |
| `rate` | `92` | темп речи, 50–150 |
| `pitch` | `94` | высота голоса, 50–150 |
| `analysis_enabled` | `true` | оценивать запрос классификатором |
| `analysis_model` | `haiku` | модель классификатора |
| `analysis_timeout_ms` | `8000` | сколько ждать классификатор; не успел — значок ⏱ и подсказка |
| `context_warn_tokens` | `200000` | с какого размера контекста предлагать продолжить в новой сессии |
| `context_repeat_tokens` | `100000` | как часто повторять это предложение |

Кроме файла настроек:

- **промпты** — любой файл из `prompts/` перекрывается одноимённым в
  `~/.config/robot-voice-hook/prompts/`; правится живая копия, плагинная держится сведённой с ней;
- `ROBOT_VOICE_RAW=1` — сырой ответ классификатора в stderr;
- `ROBOT_VOICE_CLAUDE_BIN` — чем запускать классификатор, если `claude` не в `PATH`;
- `ROBOT_VOICE_HOOK_DRY_RUN=1` — прогон без звука, метрик и записи состояния;
- `METRICS_BIN` — приёмник метрик (по умолчанию `~/Projects/home/metrics/bin/metrics`;
  нет его — метрики молча не пишутся, на работу робота это не влияет).

### Почему набор значков — настройка

У кружков 🟡 и 🟢 есть глифы в монохромном Noto Sans Symbols2, и JBR берёт его раньше Noto Color
Emoji — в IDEA кружки выходят серыми. Лечится правилом fontconfig (урезанная копия Noto Color
Emoji только с `Emoji_Presentation=Yes`, первой для `monospace`), но правило машинное: на машине
без него надо вернуть книги — у них такого двойника нет, они цветные везде.

Поэтому набор переключается одним ключом, а не правкой кода и трёх промптов: в текстах стоят
`{{mark_high}}`, `{{mark_mid}}`, `{{mark_low}}`, и подставляет их хук.

Устройство правила fontconfig и замеры — `prompt-vault @/it/linux/idea-emoji-color/`.

## Легенда значка

### Перед работой: `🤖 <реплика> 🟢`

Ставит `hooks/inject-voice-rule.js` по ответу классификатора. Виден только при `debug: true`.
Цвет — **прогноз**: сколько робот разглядел в постановке.

| 🟢 | 🟡 | 🔴 |
|---|---|---|
| цель и результат названы, остаются мелочи | направление видно, половину придётся выдумать | цель непонятна, без вопроса работать нельзя |

Вместо цвета может стоять значок отказа — тогда оценки нет, и робот скажет о причине словами:

| Значок | Что случилось | Лечение |
|---|---|---|
| ⏱ | классификатор не уложился в `analysis_timeout_ms` и снят по таймеру | поднять таймаут или `analysis_enabled: false` |
| ❔ | не запустился, ответил мусором или оценка выключена | проверить доступность `claude`, см. `ROBOT_VOICE_RAW=1` |

Гонку устраивает `spawnSync`: у него запускается процесс классификатора и таймер, чей результат
раньше — тот и берётся. Проигрыш по таймеру отличается от прочих отказов кодом `ETIMEDOUT`, и
только он чинится настройкой — поэтому у него отдельный значок и отдельная подсказка.

**Объём работы значком не показывается.** Он слышен в самой реплике: правила требуют, чтобы по
словам угадывались обе оси — и понятность, и сколько там работы. Большая задача — это не «плохо»,
цветом её не выразить, а второй значок в строке пришлось бы каждый раз расшифровывать.

### После работы: `🤖 <реплика> 🟡`

Ставит сам агент по правилам `prompts/finish.md`. Цвет — **факт**: сколько пришлось додумать по
итогу работы. Шкала та же, поэтому два цвета сравнимы между собой.

🚨 Как справился робот, значок не сообщает — это работа слов. «Сделал и проверил», «полдела ждёт
вашего ответа», «переделывал дважды», «работать не начинал» говорится репликой.

### Как этим пользоваться

| Что видно | Что это значит | Что делать в следующий раз |
|---|---|---|
| 🟢 → 🟢 | постановка была полной | ничего, формат работает |
| 🟢 → 🟡 | звучало ясно, а половину пришлось додумать | назвать ожидаемый результат и границы, а не только действие |
| 🟢 → 🔴 | выяснилось, что задача не та, и ход ушёл впустую | назвать нежелательный вариант заранее («не в памяти, а на диске») |
| 🔴 → 🔴 | работа не начиналась, ход ушёл на вопрос | сразу указывать объект: какой файл, какая машина, что считать готовым |
| 🟡 → 🟢 | вопрос по ходу дела снял недосказанность | ничего, но эти детали стоили одного круга |

Финальный цвет ставится по итогу и намеренно не подгоняется под стартовый: расхождение — это и
есть обратная связь, ради которой всё сделано.

## Совет после реплики

Цвет — только указатель; содержательная часть обратной связи идёт словами сразу за репликой.
Один совет по фактам этой задачи, отвечающий на «что сделать иначе в следующий раз»: какого
факта не хватило и как он выглядел бы в запросе, какое допущение робот принял за человека,
стоило ли разбить задачу или назвать порядок шагов, что осталось проверить руками.

🚨 Совет не выдумывается. Постановка была полной — робот прямо говорит, что советовать нечего.
Совет, появляющийся всегда, перестают читать, и настоящий сигнал тонет вместе с ним.

## «Контекст разросся» — меню продолжения, а не совет

Размер контекста берётся из `usage` последнего ответа модели в стенограмме: это настоящее число
токенов в окне, а не размер файла. Модель своего окна не видит, поэтому факт передаёт хук, и он
же решает, пора ли — порог `context_warn_tokens`.

По сигналу агент доделывает ход, пишет итог по плану (всё сделано — можно закрывать, или сколько
осталось) и показывает меню: новая сессия одной строкой запуска или продолжить здесь.

- **Не на каждом ходе.** Сигнал звучит при переходе порога и дальше не чаще, чем раз в
  `context_repeat_tokens` на сессию: вопрос на каждом ходе приучил бы отвечать «здесь», не читая.
  Когда предложено, помнит `~/.config/robot-voice-hook/context-offers.json`.
- **Не в фоновом прогоне.** При `AI_DISPATCHER_RUN` сигнала нет: меню там некому ответить.
- **Без значка.** Цвет отвечает только за понятность постановки.

## Что хук отдаёт и когда

Claude Code кладёт `additionalContext` длиннее 10 000 символов в файл, а в контекст ставит превью
в 2 КБ, которое живёт до конца сессии. Поэтому неизменные правила не едут с каждым запросом.

| Когда | Что | Сколько |
|---|---|---|
| `SessionStart` (если хук подключён) или первые запросы сессии | правила кусками по ≤ 8 000 символов, по одному на событие; ядро первым в первом куске | два куска, ~14 КБ и ~9 КБ |
| после сжатия контекста | те же куски заново: хук считает `compact_boundary` (Claude) и `compacted` (Codex) в стенограмме | как выше |
| каждый запрос | переменная часть: оценка классификатора, недавние реплики, уровень мата, звук | ~1.3 КБ |
| `<task-notification>` | одна строка «ответ кончается строкой робота», без классификатора и без звука | 288 байт |

Сколько кусков доставлено какой сессии и при каком числе сжатий — `~/.config/robot-voice-hook/rules-delivery.json`.
Без `SessionStart` правила приезжают с первыми двумя запросами — Codex новый хук без доверия
пользователя не запустит, и этот путь работает у него сам.

Каждый вызов пишет метрику `robot_voice_injection_bytes` с лейблом `part`: `core` — ядро,
`rules` — кусок правил, `turn` — переменная часть, `notification` — она же на уведомлении. Ядро
больше 1 900 байт или сообщение длиннее 10 000 символов хук называет пользователю в
`systemMessage`, а не молча.

## Устройство

| Путь | Что там |
|---|---|
| `hooks/hooks.json` | подписка на `UserPromptSubmit` и `Stop` через `${CLAUDE_PLUGIN_ROOT}` |
| `hooks/inject-voice-rule.js` | ядро: настройки, набор значков, куски правил, стартовая реплика |
| `hooks/analyze-prompt.js` | классификатор: запуск дочернего `claude` и разбор стенограммы |
| `hooks/speak-stop.js` | финальная строка: достаёт реплику из ответа и произносит |
| `hooks/recent-phrases.js` | история реплик, чтобы не повторяться между сессиями |
| `hooks/metrics.js` | точка метрики, молча не работающая без приёмника |
| `prompts/` | правила: стиль, цели, старт, вопрос, финал, продолжение, классификатор |
| `scripts/speak-brief` | синтез речи RHVoice + `ffplay` |

Состояние (история реплик, счётчики доставки, предложения о новой сессии) живёт в
`~/.config/robot-voice-hook/` и в репозиторий не попадает.
